# Map Home — Map-Based Landing Page (iOS)

A Proton VPN–inspired landing page: a stylized dark world map showing the
user's approximate position, the selected tunnel's endpoint(s), and animated
arcs for the traffic path. It is **additive** — the classic tunnels list
remains the default landing page. Everything lives under
`Sources/WireGuardApp/UI/iOS/MapHome/`.

## Entry Points

- Globe button in the tunnels list navigation bar (`TunnelsListTableViewController`).
- Optional **Open at launch**: Settings → "Map Home" → *Open map at launch*
  (also toggleable from the map's ⋯ menu). When enabled, `MainViewController`
  presents the map full-screen once the `TunnelsManager` is ready.

## What the Map Shows

| Selection | Rendering |
| --- | --- |
| Single tunnel | One arc: user → endpoint. Animated "beads" flow while active; faint line while disconnected; marching dashes while connecting. |
| Tunnel-in-tunnel | Two chained arcs: user → outer (Server A) → inner (Server B), both animated while active. |
| Failover group | Arc to the **active** member (from live `activeConfig` state), static dashed arcs to standby members, and an amber pulsing dashed arc/marker for a **hot spare** whose handshake is fresh (< 180 s, matching `REJECT_AFTER_TIME`). |

The user's marker pulses green when protected, red when unprotected. The
status header mirrors the tunnel status (`You are protected` / `Connecting…` /
`You are unprotected`) and a pill shows the exit location plus the discovered
public IP (when IP Discovery is enabled).

## Components

- `ConnectionMapView` — CoreAnimation renderer. Web Mercator projection of
  embedded landmass outlines (single `CAShapeLayer`, even-odd fill), per-link
  `CAShapeLayer`s (dash-phase animations for flow), per-node marker layers,
  and an auto-camera that frames the scene's points with insets so the header
  and card never cover them. Camera changes morph smoothly: every path keeps
  an identical element structure across cameras, so `path` animations
  interpolate exactly. Longitudes wrap (3 world copies) so transpacific arcs
  render correctly.
- `MapScene` / `MapSceneBuilder` — pure model of nodes/links built from the
  selected `TunnelContainer`, the latest group state (IPC), the location
  store, and the user's approximate location. `Equatable`, so pollers skip
  redundant redraws.
- `MapHomeViewController` — the landing page. Selection menu (failover groups,
  TiT groups, tunnels), Connect/Disconnect button (mirrors list semantics,
  including disabling on-demand before disconnecting), live polling
  (2.5 s) of group state via the existing IPC message types, and a chip
  prompting to set locations for endpoints that don't have one.
- `EndpointLocationsViewController` / `LocationPickerViewController` —
  assign a city to each tunnel (and "My Location"), with search.

## Locations & Privacy

- **Endpoint locations are user-assigned** (no geo-IP calls): tunnel name →
  `EndpointLocation`, persisted as JSON in the shared app group defaults
  (`EndpointLocationStore`, same pattern as `RecentTunnelsTracker`; kept in
  sync on rename/remove/cleanup from `TunnelsManager`).
- **User location is approximate and permission-free**: manual override if
  set, else the device time zone's representative coordinates
  (`TimeZoneLocationTable`, from tzdb `zone1970.tab`), else a rough
  longitude from the GMT offset. No CoreLocation, no network lookups.

## Embedded Data (no bundle resources)

Generated by `scripts/generate-map-data.py` into Swift sources, so no
`project.yml`/resource-phase changes are needed:

- `WorldMapData.swift` — Natural Earth 1:110m land polygons (public domain),
  simplified and polyline-encoded at 0.1° (~3 k points, ~9 KB).
- `MapCityDatabase.swift` — ~530 cities (capitals + >1 M population + common
  VPN hubs) from Natural Earth 1:50m populated places, for the picker.
- `TimeZoneLocationTable.swift` — 312 IANA zones → coordinates.

Regenerate with `python3 scripts/generate-map-data.py`.

## Live State

Uses the existing group-state IPC (`TunnelsManager.getGroupState(kind:)`):
failover message type 1 (`activeConfig`, `hotSpareConfigIndex`,
`hotSpareHandshakeAge`, `rxBytes`/`txBytes`, …) and TiT message type 4
(`outer*`/`inner*` stats). Regular tunnels use
`getRuntimeTunnelConfiguration` for rx/tx. While the map is presented it
takes over `tunnelsManager.activationDelegate` (restored on dismissal) so
activation errors alert on top of the map.

## Non-Goals (for now)

- macOS UI (the store/scene model are UIKit-free except the map view, so a
  macOS port can reuse them).
- Map gestures (pan/zoom) — the camera is automatic.
- Automatic endpoint geolocation.
